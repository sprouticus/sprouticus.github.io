# sprouticus.github.io

Source for my personal portfolio site, published via GitHub Pages at [sprouticus.github.io](https://sprouticus.github.io).

Plain static HTML/CSS/JS (no Jekyll build step — see `.nojekyll`). Edit `index.html` and `assets/css/style.css` directly.

To add photography samples, drop images into `assets/photography/` and add a matching `<figure>` entry in the gallery section of `index.html`.
